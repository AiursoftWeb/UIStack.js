# UIStack.js

Shared styles and browser resources for Aiursoft applications.

```bash
npm install @aiursoft/uistack
```

The package includes compiled assets in `dist/`. Source files are excluded from the npm package.

## Development

```bash
npm ci
npm run build
npm pack --dry-run
```

The ASP.NET Core components and demo remain in [UIStack](https://gitlab.aiursoft.com/aiursoft/uistack).
